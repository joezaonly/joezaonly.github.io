โครงสร้างที่ AI ดูแลต่อได้ · 24/08/2026

แนวคิด

รวบรวมคู่มือ โน้ต และบทเรียนทั้งหมดของเราไว้ในเว็บเดียวที่ <username>.github.io — ฟรี ไม่ต้องดูแลเซิร์ฟเวอร์ และออกแบบให้ "AI ผู้ดูแล" ช่วยเพิ่มหนังสือให้ได้อย่างปลอดภัย

สถาปัตยกรรม 4 ชั้น

  1. ชั้นข้อมูล — data/books.json เก็บรายการหนังสือทั้งหมดไว้ที่เดียว ไม่แก้ใน HTML โดยตรง
  2. ชั้นเจนเนอเรเตอร์ — สคริปต์ Python อ่าน JSON + เทมเพลต แล้วสร้าง index.html ใหม่เสมอ มีโหมด --check สำหรับทดสอบว่าเว็บไม่หลุดจากข้อมูล
  3. ชั้นเนื้อหา — หนังสือแต่ละเล่มเป็นไฟล์ HTML ในโฟลเดอร์ books/ อ่านได้ทันทีบนทุกอุปกรณ์
  4. ชั้นกติกา — ไฟล์ AGENTS.md กำหนดว่า AI ทำอะไรได้เลย และอะไรต้องขออนุมัติก่อน (เช่น เผยแพร่สู่สาธารณะ)

ทำไมต้องแยกข้อมูลออกจากหน้าเว็บ

เพราะการแก้หน้า HTML ตรงๆ สะสมความผิดพลาดได้ง่าย (แท็กหาย เรียงผิด ลืมลิงก์) แต่การแก้ไฟล์ JSON ใบเดียวแล้วให้สคริปต์เจนใหม่ทุกครั้ง ทำให้ผลลัพธ์ "เหมือนเดิมทุกครั้ง" และตรวจได้ด้วยคำสั่งเดียว

รายการต้องทำก่อนเผยแพร่ (quality gates)

python scripts/build_shelf.py --check   # เว็บตรงกับข้อมูลไหม
git diff --check                        # ไม่มีช่องว่างเกิน/ขัดแย้ง

กติกาความปลอดภัยสำหรับ AI ผู้ดูแล

  • AI เพิ่ม/แก้ไขหนังสือ แก้ JSON สร้างปก ทดสอบ และเตรียม commit ได้เอง
  • แต่ push ขึ้นเว็บสาธารณะต้องได้รับอนุมัติจากเจ้าของก่อนเสมอ
  • ห้าม commit ข้อมูลส่วนตัว: โทเคน, คุกกี้, บราวเซอร์โปรไฟล์, พาทในเครื่อง
