ปิดการขออนุมัติของ Hermes Agent ให้ถูกจุด

โหมดอนุมัติมี 2 ชั้น — ตั้งชั้นเดียวไม่พอ · 24/08/2026

อาการ

ตั้ง approvals.mode = off แล้ว แต่พอพิมพ์ /new หรือ /reset ระบบยังเด้งถามยืนยันอยู่

สาเหตุ

การถามยืนยันของ Hermes แยกเป็น สองประตูอิสระ:

  1. approvals.mode (smart / manual / off) — คุมเฉพาะการอนุมัติ คำสั่งเชลล์ ที่รันผ่าน terminal
  2. approvals.destructive_slash_confirm (ค่าเริ่มต้น: true) — คุมการยืนยัน คำสั่ง slash ที่ทำลายล้าง เช่น /new, /reset, /undo

ประตูที่สองไม่สนใจค่าของประตูแรก จึงต้องปิดทั้งสองตัว

วิธีแก้

hermes config set approvals.mode off
hermes config set approvals.destructive_slash_confirm false

หรือตอนเด้งถามครั้งแรก เลือกตัวเลือก "ไม่ต้องถามอีก" ระบบจะบันทึกค่าให้เอง

ข้อควรระวัง

  • โหมด off ข้ามการถามทั้งหมด แต่ blocklist ระดับสูงสุด (คำสั่งล้างดิสก์ ปิดเครื่อง ฯลฯ) ยังคงบล็อกถาวร — ออกแบบมาไม่ให้ปิดได้
  • ค่าใน config.yaml เป็นส่วนหนึ่งของระบบความปลอดภัย — อย่าให้ AI แก้ไฟล์นี้เองระหว่างมีสิทธิ์อนุมัติเต็ม (ระบบมีการป้องกันการแก้ผ่าน agent อยู่แล้ว)
  • ถ้าอยากได้ตรงกลาง: ใช้ approvals.mode: smart ที่จะถามเฉพาะคำสั่งที่ดูเสี่ยง
